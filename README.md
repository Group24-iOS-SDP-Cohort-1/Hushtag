# Hushtag

**Hushtag** is an AI-powered content creation assistant that helps creators turn ideas into engaging scripts, titles, and descriptions — all in one seamless workflow.

From ideation to execution, Hushtag simplifies the entire content creation process using intelligent automation and a clean, intuitive interface.

---

## Features

### Idea Management

* Discover and manage creative content ideas
* Save and like ideas for later use
* View detailed idea insights including:

  * Description
  * Hashtags
  * Performance analytics (views, likes)

---

### AI Script Generation

* Generate **short-form video scripts** using AI
* Automatically create:

  * Script
  * Title
  * Description
* Smart suggestions based on platform (YouTube, Instagram, etc.)

---

### Chat-Based Workflow

* Interactive AI chat interface for content creation
* Context-aware responses using conversation history
* Mark messages as:

  * Script
  * Title
  * Description
* Automatically builds a complete post from chat

---

### Performance Insights

* Analyze idea performance using:

  * Average views
  * Average likes
* Helps creators choose high-performing content directions

---

### Script Organization

* Save and manage generated scripts
* Tag scripts to brand deals
* Expand and refine descriptions using AI
* View all scripts in a structured layout

---

### Search & Filtering

* Search scripts and ideas by:

  * Title
  * Tags
* Real-time filtering for quick access

---

## Tech Stack

### Frontend

* **Swift (UIKit)**
* UICollectionView + Compositional Layout
* UITableView for chat UI

### AI Integration

* Apple Intelligence (on-device AI)
* Gemini API (content generation)

### Backend

* **Supabase**

  * PostgreSQL database
  * Authentication
  * Real-time data handling

---

## Workflow

1. Select or create an idea
2. Start AI chat
3. Generate script/title/description
4. Mark relevant messages
5. Save structured script
6. Analyze performance or schedule content
